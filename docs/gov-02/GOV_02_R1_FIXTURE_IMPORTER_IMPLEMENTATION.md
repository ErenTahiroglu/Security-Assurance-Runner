# GOV-02 R1 — fixture importer contract

**NONPRODUCTION; source facts verified 2026-10-31 before schema freeze.** The owner submitted the bounded implementation task; design acceptance is separate from operational scanner approval.

Gitleaks v8.30.1 source [report/json.go](https://github.com/gitleaks/gitleaks/blob/v8.30.1/report/json.go) encodes `[]Finding` as a top-level JSON array; a nil Go slice may encode as `null`. [report/finding.go](https://github.com/gitleaks/gitleaks/blob/v8.30.1/report/finding.go) declares string fields `RuleID`, `Description`, `Match`, `Secret`, `File`, `SymlinkFile`, `Commit`, `Link`, `Author`, `Email`, `Date`, `Message`, `Fingerprint`; integer `StartLine`, `EndLine`, `StartColumn`, `EndColumn`; float32 `Entropy`; string slice `Tags`; optional nested `Fragment`. `Link` and `Fragment` use `omitempty`; `Line` has `json:"-"` and is absent from native JSON. [json_test.go](https://github.com/gitleaks/gitleaks/blob/v8.30.1/report/json_test.go) exercises arrays, including empty; [cmd/root.go](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/root.go) shows scan errors and default findings may both exit 1. No scanner or rules were downloaded or run.

The importer defines a strict **fixture subset**, not upstream mandatory fields: known string fields may be omitted; when present they must be strings; coordinates must be nonnegative integers; Entropy must be numeric within the float32 finite range; Tags may be an array of strings or null. Unknown fields, including `Line`, and non-null `Fragment` are rejected. No native field is asserted mandatory merely from the Go struct. `[]`, `null`, and missing bytes remain distinct; empty or null never proves real coverage. Raw strings, paths, URLs, fingerprints, descriptions, match values and secrets are never returned; only presence flags and numeric coordinates survive. Thus native rule/fingerprint values are deliberately omitted for privacy, not authenticated or synthesized. Strings are bounded by 4096 bytes, input by 65536 bytes, findings by 256, tags by 64; serde_json's default recursion limit applies and non-null Fragment is unsupported. A finite 65536-byte bound also limits fields and parse allocation; known fields only are accepted and duplicates reject.

Receipt is `test_only`, `scanner_executed=false`, `provider_authenticated=false`, `tool_binary_verified=false`, `coverage_verified=false`, `policy_authority_verified=false`, `operational_pass=false`. It cannot assert operational BLOCK. No raw digest is emitted by default, avoiding low-entropy correlation exposure. The API does not resolve or access paths, links, archives or external systems; all textual metadata is discarded. Errors are fixed categories without offending text; internal raw structures are not Debug or Serialize. No trusted-root mutation or existing GOV-01 changes.
