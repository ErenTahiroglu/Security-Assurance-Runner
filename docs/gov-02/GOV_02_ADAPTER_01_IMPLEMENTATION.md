# GOV-02 ADAPTER-01 — bounded native evidence assessment

Author candidate; not independent acceptance. `gitleaks_adapter::assess(report, plan, claim)` is an offline library API, not a scanner launcher. Version 1 plan and execution inputs are **caller-declared**, including identities, digests, run/stage/attempt, claimed execution state, exit, report size/hash and errors/skips. Comparing caller claims can find contradictions but authenticates neither party. Inputs have no Debug/Serialize implementation. Receipt exports fixed labels, numeric counts and booleans, never raw rule IDs, paths, URLs, fingerprints, secrets, native strings or report digests. No host, provider, tool or policy authority has been enrolled or independently verified.

It reuses `interpret_gitleaks_fixture_v2`'s bounded parser: maximum 65,536 bytes, 256 findings, 4,096-byte strings and 64 tags. Unsupported fields and non-null Fragment fail closed; duplicate keys and invalid UTF-8 fail. `null`, empty array, missing bytes and invalid data have distinct states. A profile-usable finding is a selected strict interpretation, not a universal producer requirement: missing fingerprint, location or file can make otherwise legitimate native output insufficient. The PILOT-01-specific exact REDACTED/marker/coordinate oracle is not used for native ingestion. [v8.30.1 finding](https://github.com/gitleaks/gitleaks/blob/v8.30.1/report/finding.go), [JSON serializer](https://github.com/gitleaks/gitleaks/blob/v8.30.1/report/json.go), [exit handling](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/root.go), [directory execution](https://github.com/gitleaks/gitleaks/blob/v8.30.1/cmd/directory.go). Full redaction substitutes the secret in Match; no universal redaction is assumed.

`unique_catalog_rules_seen` counts distinct caller-declared catalog indexes only. Missing findings do not establish that a rule did or did not execute; `required_rules_without_findings` is not missing rule coverage. Repeated findings cannot satisfy distinct rule identities. Raw fingerprint is not a cryptographic identity. Report hash comparison is local integrity against a caller assertion, not authenticated provenance. An exit code 1 can indicate a finding or error; all nonzero codes are unresolved. Incomplete/cancelled execution may still have findings. Empty JSON, successful exit and matching claims cannot establish coverage or authority. `policy_decision` is always existing `Decision::Indeterminate`; verification flags and operational PASS are always false. Claimed execution is not observed independent execution. No operational BLOCK is produced.

Future integration requires an independently authenticated owner-approved plan and execution boundary, a trusted evidence source, exact run/attempt, binary, input, rule/config and output binding, validated coverage and supported producer versions. This adapter does not launch or download tools and does not expose a CLI operation.
