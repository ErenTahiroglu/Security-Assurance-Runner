# Security policy

SAR is documentation-only at this point and is not a working security product. Do not submit real secrets, private vulnerability details, target data, or exploit material in a public issue.

For a suspected vulnerability, use GitHub's private vulnerability reporting feature if enabled. If unavailable, contact the repository owner through the private contact route shown on the owner's GitHub profile. No response deadline, supported release, or operational incident-response service is promised.

Provide a concise description, affected commit or file, impact, and safe reproduction details. Do not test systems without ownership or explicit authorization. The owner will determine whether and how to coordinate disclosure.
