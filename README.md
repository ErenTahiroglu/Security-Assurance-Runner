# Security-Assurance-Runner (SAR)

**Owner:** Eren Tahiroğlu
**Status:** BOOTSTRAP / ARCHITECTURE ONLY — NOT A WORKING SECURITY SCANNER, NOT AN INDEPENDENTLY VALIDATED SECURITY PRODUCT.

SAR is a planned system for orchestrating security tools, normalizing findings, and evaluating evidence-aware policy. It is publicly source-available under PolyForm Noncommercial License 1.0.0, not OSI-approved open-source software. No scanner, policy engine, AI feature, or evidence verifier is implemented.

Proposed v1: SAST, SCA, secret/configuration and supply-chain assessment, authorized isolated DAST and fuzzing, control mapping, auditable reporting, CI policy, CI/LOCAL/HYBRID modes, evidence export. Proposed v2 adds opt-in AI review and separately authorized AI-agent adversarial testing. AI is off by default.
